### 3. Bugs encontrados hoy
**Bug nuevo — Overtime y delta no se calculan automáticamente.** Severidad: **alta** (es la objeción central de este cargo — "cronometrador: exige que el control de horarios calcule overtime automáticamente, no a mano"). Confirmado en vivo: el campo "OVERTIME" es un selector manual (`No ▾`) y "DELTA (MIN.)" es un input de texto libre — ninguno se deriva de "WRAP PREVISTO"/"WRAP REAL". El usuario tiene que calcular y tipear la diferencia él mismo.

- Reconfirmado dos veces (lectura de código + interacción en vivo con Playwright).

### 4. Solución propuesta
Calcular `delta_minutos` y `overtime` (cliente o servidor) a partir de `hora_prevista_wrap`/`hora_real_wrap`, con un umbral configurable (ej. >30 min = "Alerta", >60 min o fuera de convenio = "Confirmado"). Dejar ambos como solo lectura. Si se necesita un override humano (razones legales puntuales), agregar un campo separado `overtime_override` con motivo obligatorio — nunca reemplazar el cálculo por default.
